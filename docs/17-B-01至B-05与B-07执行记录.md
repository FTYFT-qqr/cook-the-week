## B-06 实现边界

- 本机/DB 模式继续由本地存储保存界面内领域结果。
- API 模式不再把界面整周快照回写服务端；页面动作直接表达服务端意图，服务端负责重新计算权威方案、清单和派生字段。
- API 撤销优先执行服务端返回的精确撤销指令；本机模式继续使用本地快照撤销。
- 多餐页面的控件 key 增加日期、餐次和槽位索引，避免同一页面重复控件导致 Streamlit 启动失败。
