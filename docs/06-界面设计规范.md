# 界面设计规范（v1.1 起生效）

> 依据：`docs/03-客户体验与界面改造建议-第二篇.md`（V-xx 视觉诊断 + 第 4 节设计规格）与
> `docs/04-界面逐屏标注-第三篇-需求与生成页.md`（P-01～P-13 + 第 4 节改版稿）。
> 功能与流程的基线是 `docs/05-功能与界面交互设计.md`：**流程以 05 为准、样式取值以本文件为准**。
> 本文件是**施工图**：以后新增任何页面/组件，都从这里取值，不要另起一套颜色或字号。
> 落地位置：色板与主题在 `.streamlit/config.toml`；组件样式在 `app.py` 顶部样式表。

---

## 1. 四条硬规则（先看这个）

1. **一支暖橙主色**（`#E8663C`）；**红色只用于「危险 / 错误」**，不再做品牌色与交互色。
2. **颜色只表达状态**：分类、耗时、难度、辣度等一律**中性灰芯片**；一屏内色相 ≤ 4。
3. **emoji 退出图标系统**：导航、标题、按钮、标签里不出现 emoji；全站只保留 ❤️（收藏）与 📌（定住）两个情感符号，且**不进按钮文字**。
4. **每行要么填满、要么只放一个全宽控件**；**一屏只有一个焦点**，提示最多一条、用一行文字而不是彩色横幅。

## 2. 色板（6 支，用完为止）

| 用途 | 值 | 只用于 |
|---|---|---|
| 品牌主色 | `#E8663C` | 主按钮、当前选中、收藏状态、关键数字 |
| 主色浅底 | `#FDEEE8` | 收藏卡片底、选中行底、今晚高亮 |
| 页面背景（暖白） | `#FAF8F5` | 全站底色 |
| 卡片 / 面板 | `#FFFFFF` | 卡片、侧栏、输入控件底 |
| 文字 主 / 次 / 弱 | `#1F2937` / `#6B7280` / `#9CA3AF` | 三级灰，不再引第四种 |
| 语义色（仅状态） | 安全 `#2F855A`、注意 `#B7791F`、危险 `#C53030` | 忌口安全、超时、超预算、过敏冲突 |
| 分隔线 / 中性底 | `#ECE7DF` / `#F3F1EC` | 边线、芯片底、分类条 |

**不要**：浅靛蓝芯片、粉色收藏、绿色目标标签、橙色装饰边线——这些已全部移除。

## 3. 字号与行高

| 层级 | 字号 | 字重 | 行高 | 用在哪 |
|---|---|---|---|---|
| 页面标题 | 28px | 700 | 1.35 | 每页顶部（`st.title`） |
| 区块标题 | 20px | 600 | 1.4 | 整周总览、快速开始（`###`） |
| 分组小标题 | 17px | 600 | 1.45 | 表单四组、列表标题（`####`） |
| 卡片标题 | 17px | 600 | — | 菜名、方案名 |
| 正文 / 理由 | 15px | 400 | 1.65 | 说明、推荐理由 |
| 注释 | 13px | 400 | 1.55 | 口径、来源、辅助信息（一行小字 `.line` / `st.caption`） |
| 关键数字 | 26px | 700 | 1.2 | 本周花费、命中收藏、忌口冲突、最费时 |

**硬规则**：不出现 12px 及以下正文；中文行高 ≥ 1.6；注释靠「浅色 + 小一号」降级，不靠更细字重。

## 4. 间距

`4` 的倍数：芯片之间 6 / 芯片内边距 (2,8) / 卡片内边距 16 / 卡片之间 12 / 区块之间 32（配 `###` 标题自带的上边距）。

## 5. 组件规范

### 5.1 菜品卡 `.dish-card`
从上到下固定四段，保证所有卡片等高（`min-height:126px`）：
1. 菜名（17/600）+ 右侧状态文字（`已收藏` 主色 / `已排除` 中性灰）；
2. 标签行：**固定 3 个中性灰芯片**（默认「时间 · 难度 · 类别」，有辣度时用辣度替掉类别）；
3. 推荐理由：一行到两行（15px，浅底圆角，超出省略）；
4. 操作区：**换一道**（次级按钮，主操作）+ **喜欢 / 不喜欢**（次级、低对比），三个等宽，同一基线。

状态表达（V-07）：已收藏 = 主色描边 + 主色浅底 + `已收藏` 文字；已排除 = 灰底 + 灰字 + `已排除` 文字。**灰度打印/色盲也能分辨**。

### 5.2 今晚大卡 `.hero`
首屏唯一焦点：`今晚 · 第 N 天 周几 日期`（13px 主色小字）→ 菜名（22/700）→ `约 X 分钟 · 预计 ¥X`（15px 次要）→ 一句理由。下方一行三个操作，作用于今晚第一道，右侧小字说明作用对象。

### 5.3 一行数字 `.statrow`
不要一排等宽的白色卡片（V-09）。用「大数字（26/700）+ 灰色小字说明」横向排列，`flex-wrap` 自适应；数字按状态着色（安全绿 / 注意黄 / 危险红）。

### 5.4 整周总览 `.day-row`
每天一行、等宽：`第 N 天 周几 日期`（148px 固定）+ 菜名（弹性）+ `X 分钟 · ¥X`（右对齐 148px）。
今天：主色浅底 + `今晚` 标记；已过的日子：整体降为 55% 透明 + `已过` 标记（E-01）。

### 5.5 提示 `.line`
一行 13px 浅灰文字；安全类用 `.line.ok`（绿）、问题类用 `.line.bad`（红 + 字重 600）。**不再使用彩色整条横幅**；操作结果同时给右下角 toast。

### 5.6 清单（到店模式）
一行一样：`复选框 食材　数量`，「用于」收进复选框的悬停提示；分类用中性灰 `.cat-bar` 分隔，**有内容才占位**；已买的行沉到该分类末尾并整体降透明度；顶部一条细进度 + `已买 X / N 样，还剩 Y 样`；底部「清除勾选」（次级）｜「带走清单」（主按钮，展开导出区）。

### 5.7 A4 打印 `.a4`
一页装下：上半「本周晚餐菜单」表格（周几 · 日期 · 菜名 · 用时 · 金额 + 合计行），下半「买菜清单」两栏（每项前一个 `□` 可手写打勾），页脚一行「本周预计 ¥X / 预算 ¥X + 折算口径」。**黑白友好**：只用边框与方框，不用颜色、不用 emoji。

---

## 6. 布局与响应式

- 断点：`<640px` 单列；`640–1024px` 两列；`>1024px` 三/四列。**只维护一套组件、只切换列数**（V-16）。
- 窄屏下：所有 `st.columns` 堆成单列；**例外**：菜品操作按钮保持一行三个、底部导航保持一行四个（用 `st-key-*` 精确覆盖）。
- 手机：正文顶部不重复导航，改用**底部固定任务栏**（按宽度自动显示，不给用户开关，V-14）；触控目标 ≥ 44px。
- 侧栏只承担导航：品牌 + 四个任务栏大按钮 + 一行「方案 X · 生成日期」。计数、开关、隐私说明都在各自页面正文里（V-13 / P-02）。

---

## 7. 主题与框架痕迹

`.streamlit/config.toml`：`[theme] base="light"` + 上面那套色值（**锁定浅色**，不做半跟随系统的深色，V-15 / P-12）；
`[client] toolbarMode="minimal"` 去掉右上角 Deploy 与汉堡菜单（P-01）；页签标题统一为「晚餐规划 · 一周菜单与买菜清单」。

## 8. 自查清单（改完界面后逐条过）

1. 截图缩到 25%，还能一眼看出重点在哪吗？
2. 转成灰度，`已收藏 / 已排除` 还分得清吗？
3. 一屏之内有几种色相？> 4 不合格。
4. 还有 12px 以下的文字吗？
5. 一屏里有几处在争焦点（横幅/提示条/卡片）？> 1 不合格。
6. 卡片右边的按钮是否在同一条视线上对齐？
7. 把所有 emoji 拿掉，界面还成立吗？
8. 手机上能不能单手、一屏内勾掉一样买好的菜？
9. 打印预览是不是一页 A4、没有按钮和侧栏？
10. 系统切到深色模式，界面有没有变"脏"？
