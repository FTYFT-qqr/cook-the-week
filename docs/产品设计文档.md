# Recipe-Planner · 一周食谱与买菜清单规划 Agent

> 版本：v1 草案 ｜ 状态：MVP 范围已确认 ｜ 配套备忘：`D:\cook\聊天小结-recipe-planner项目.md`

## 1. 产品概述

**一句话定位**：一个"告诉它家里几口人、忌口和预算，它帮你排好一周晚餐、并直接给出买菜清单"的 AI 助手。

- **目标用户**：需要日常做饭、但不想每天纠结"吃什么、买什么"的家庭用户（个人/情侣/小家庭）。
- **核心价值**：把"想菜 → 搭配 → 校验 → 买菜"这件琐事一次搞定，结果**可解释**（每道菜说明为什么选它）、**可执行**（清单已去重、已扣库存、已按预算控制）。
- **产品形态**：AI Agent（LLM 规划 + 确定性校验），先以网页（Streamlit）演示，核心是背后的 Agent 编排能力。

## 2. 主题方向

**用 Agent 做"生活化、能落地"的软件产品**，重点展示三层能力：

1. **知识库检索（RAG）**：菜谱做成结构化知识库，按约束检索，而不是写死在提示词里；
2. **多步智能规划（LangGraph）**：收集 → 检索 → 排菜 → 校验 → 修正 → 出清单的状态机编排；
3. **可靠性与可解释**：校验和修正用确定性代码完成，LLM 负责"选菜与说理"，两者分工、结果可信。

## 3. 核心功能（MVP v1）

### 输入（用户填写，均可选填、带默认值）
- 几人、排几天（默认 3 天）
- 忌口 / 过敏原（硬性排除）
- 口味偏好、健康目标（减脂/控糖/清淡/高蛋白/省钱）
- 做饭时长上限、预算（元/人/天）、家里已有食材
- **菜品喜好：❤️ 喜欢的菜（软性优先，尽量分散安排）/ 🚫 不喜欢的菜（硬性排除）**；自动存入客户档案，下次打开自动带入，为“越用越懂你”的智能菜单打基础

### 处理流程（Agent 编排）
- **检索**：从菜谱库按忌口、口味、目标、时长、预算过滤候选菜；
- **排菜**：LLM 按天搭配菜单，每道菜附一句"为什么选它"；
- **校验**：确定性检查过敏、重复、超预算、超时长、目标标签；
- **修正**：发现问题自动重排，最多 3 次，仍失败则说明原因；
- **出清单**：汇总买菜清单，按蔬菜/肉蛋/主食/调料分类，扣除已有食材并去重。

### 输出
- 每天的菜单 + 每道菜的推荐理由；
- 可直接照着买的分类买菜清单；
- 结构化结果，便于后续存档、评估。

### 界面（2 个页面）
1. **🍽️ 菜单规划**：填需求 → 生成菜单 → 在每日菜单上**逐道反馈**：
   - **🔄 换一道**：只换今晚这道，**不改口味偏好**（临时调整）；
   - **❤️ 喜欢**：记住偏好并优先安排（本次菜单不变，可一键撤销）；
   - **🚫 不喜欢**：记住并只换掉这一天，以后不再出现（可一键撤销）；
   - 反馈只影响被点击的那一道菜与那一天，**不会整周重排**；「第几天」的标签位置在反馈后保留；
   - 买菜清单**按人数折算**（菜谱为 2 人份基准，≥500g 附斤数）。
2. **❤️ 我的口味档案**：两个**互相独立的可编辑列表** ——
   - ❤️ 喜欢列表：每行支持「→ 🚫 移到不喜欢」「✖ 移除」「🧹 清空」；
   - 🚫 不喜欢列表：每行支持「→ ❤️ 移到喜欢」「✖ 移除」「🧹 清空」；
   - ➕ 快速添加：从「未表态」的菜里多选，一次批量加入任一列表；
   - 📝 全部菜品挑选页：按分类/关键词浏览整个菜谱库并逐道标记。

   解决"客户事先不知道自己喜欢什么"：可以先看菜单再反馈，也可以在这里慢慢挑、随时改。

### 正式版第一步：让它「能用一周」（已实现）

> 依据 `docs/MVP到正式版-体验改进建议.md` 的第一步，目标是：**关掉页面、明天再来，这一周还是我的那一周。**

| 编号 | 能力 | 实现要点 |
|---|---|---|
| A1 | 方案持久化 + 回访 | 菜单/清单/约束一起存进 `data/saved_plans.json`（保留最近 3 份）；打开页面直接显示"你有一份 8/12–8/18 的菜单"而不是空表单；重排是**追加**，旧版可「↩️ 回到上一版」；「换一道」等改动会写回存档 |
| D1 | 界面说人话 | 前排改为：这一周大概花多少 / 最费时的一天 / 你收藏的菜命中几道 / 契合目标几道 / 忌口 0 处冲突；**候选菜谱、修正轮数、LLM、耗时、执行轨迹**收进「🔧 开发者视角」折叠区；过敏冲突用红字**顶在最上方**（不折叠） |
| D2 | 整周总览 | 每天一行卡片（星期 / 日期 / 菜品 / 时长 / 花费），一屏看全，手机上自动换行 |
| F2/F3 | 清单可带走、可打勾 | 每项可勾选 + 「已买 X / N 项」进度 + 清除勾选；导出 **CSV**（带 BOM，Excel 不乱码）、**复制纯文本**（发微信/备忘录）、**可打印视图**（整周菜单 + 清单，Ctrl+P 或另存 PDF 贴冰箱） |
| H1 | 出一句"没办法"之前先给下一步 | 换不动 / 排不出时给可点击的：**放宽时长到 X 分钟**、**预算加 20 元/人/天**、**这天少排一道菜**；点了就自动重排 |
| E3 | 破坏性操作二次确认 + 多步撤销 | 清空「喜欢」「不喜欢」「全部档案」都要再确认一次；撤销栈最多 5 步，**两个页面都能撤**（不用跑回菜单页）；另有「🕘 改动历史」 |
| C1 | 等待有阶段、能取消 | 流水线在后台按节点推进，前台依次显示：挑菜谱 → 搭配一周 → 校验忌口/预算/时间 → 汇总清单；随时可「⏹️ 停止，我要改一下需求」 |
| G1 | 手机可用 | 「📱 手机视图」：按钮加大、清单单列一行一样、按天切换改用下拉（不再挤一排 tab） |
| B2(部分) | 按餐算耗时 | 每天显示"合计约 X 分钟"，附**下锅顺序建议**（汤/炖菜先上火 → 主菜 → 快炒 → 凉菜最后拌） |
| J1(部分) | 边界措辞 | 花费标注"按 X 人 × Y 天折算，实际以当地物价为准"；忌口块提示"请以食品包装配料表为准，下厨前再确认一次"；目标标注"方向性推荐，不等于营养计算" |

## 4. 本期不做（后续方向）

- 多轮自然语言改需求（"周二换鱼""超预算帮我省"）—— 正式版第二步最能体现 Agent 价值的一项
- 工作时间/周末分档、开工倒推（"几点能吃上饭"）、菜单历史对比与"照上周来一份"
- 不喜欢分级（这周不想看到 / 以后都不要）、换整天、整周换风格
- 采购拆批（一次买齐 / 分两次买）、可选食材标注、斤/颗/把的人类单位
- 按人忌口与家庭多成员档案
- 向量检索升级
- 精确营养计算、天气/菜价工具、图片导出、账号体系与多端同步

## 6. 验收与成功指标

一句话 demo：输入几口人 + 忌口预算 → 自动排出营养、预算内、不重复的一周晚餐并给出可执行清单。

量化指标：约束命中率、单次耗时与成本、覆盖菜谱数。

## 7. 路线图

- **v1（MVP）**：单轮排餐 + 确定性校验修正 + 买菜清单 + 逐道喜好反馈，端到端跑通；
- **v1.1（当前）**：**正式版第一步（P0）全部完成** —— 方案持久化与回访、清单可打勾/可带走、界面说人话 + 整周总览、出错给可点击的放宽选项、破坏性操作二次确认与多步撤销、等待阶段反馈与取消、手机视图；
- **v2（正式版第二步 · P1）**：多轮自然语言改需求、时间维度人性化、不喜欢分级、采购拆批、难度与厨艺匹配、状态透明、信任措辞、家庭多成员；
- **v3（正式版第三步 · P2）**：越用越懂你的可视化、家庭共享、方案历史与对比、周菜单卡/冰箱贴、使用回顾与成就。
